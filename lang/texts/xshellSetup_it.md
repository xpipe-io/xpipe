# Configurazione di Xshell

Per usare Xshell come terminale, puoi collegarlo al bridge SSH XPipe. Questo dovrebbe funzionare automaticamente una volta che la chiave SSH del bridge locale è stata aggiunta a Xshell con il nome corretto.

L'unica cosa che devi fare manualmente è aggiungere il file della chiave privata `%s` a Xshell con il nome fisso `%s`.
