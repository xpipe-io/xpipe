# Настройка Termius

Чтобы использовать Termius в качестве терминала, ты можешь подключить его к SSH-мосту XPipe. Это сработает автоматически, как только ключ SSH локального моста будет добавлен в Termius.

Единственное, что тебе нужно сделать вручную, — сначала добавить в Termius файл с закрытым ключом `%s`:

```
%s
```
