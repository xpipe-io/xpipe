# Termius kurulumu

Termius’u terminaliniz olarak kullanmak için, onu XPipe SSH köprüsüne bağlayabilirsiniz. Yerel köprü SSH anahtarı Termius’a eklendiğinde bu işlem otomatik olarak gerçekleşebilir.

Manuel olarak yapmanız gereken tek şey, önce `%s` özel anahtar dosyasını Termius'a eklemektir:

```
%s
```
