# Configuration de Termius

Pour utiliser Termius comme terminal, tu peux le connecter au pont SSH XPipe. Ça marche tout seul une fois que la clé SSH du pont local a été ajoutée à Termius.

La seule chose que tu dois faire manuellement, c'est d'ajouter d'abord le fichier de clé privée `%s` à Termius :

```
%s
```
