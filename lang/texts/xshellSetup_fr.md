# Configuration de Xshell

Pour utiliser Xshell comme terminal, tu peux le connecter au pont SSH XPipe. Ça peut fonctionner automatiquement une fois que la clé SSH du pont local a été ajoutée à Xshell avec le bon nom.

La seule chose que tu dois faire manuellement, c'est d'ajouter le fichier de clé privée `%s` à Xshell avec le nom fixe `%s`.
