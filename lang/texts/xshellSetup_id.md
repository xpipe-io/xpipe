# Pengaturan Xshell

Untuk menggunakan Xshell sebagai terminal Anda, Anda dapat menghubungkannya ke jembatan SSH XPipe. Proses ini dapat berjalan secara otomatis setelah kunci SSH jembatan lokal ditambahkan ke Xshell dengan nama yang benar.

Satu-satunya hal yang harus Anda lakukan secara manual adalah menambahkan berkas kunci pribadi `%s` ke Xshell dengan nama tetap `%s`.
