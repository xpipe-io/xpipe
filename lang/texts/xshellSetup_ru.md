# Настройка Xshell

Чтобы использовать Xshell в качестве терминала, можно подключить его к SSH-мосту XPipe. Это сработает автоматически, как только локальный SSH-ключ моста будет добавлен в Xshell под правильным именем.

Единственное, что тебе нужно сделать вручную, — это добавить файл закрытого ключа `%s` в Xshell с фиксированным именем `%s`.
